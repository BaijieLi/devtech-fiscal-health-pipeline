# Data Dictionary

This dictionary defines the canonical fields expected by the ratio engine.

## Metadata

| Field | Description |
| --- | --- |
| `locality` | County, city, or locality name |
| `fiscal_year` | Fiscal year represented by the report |
| `source_file` | Source report filename |
| `report_type` | CAFR, ACFR, Markdown, JSON, or other source type |
| `extraction_confidence` | Optional confidence score for extracted values |

## Core Financial Fields

| Field | Description |
| --- | --- |
| `cash_and_equivalents` | Government-wide cash and cash equivalents |
| `investments` | Government-wide investments |
| `current_liabilities` | Current liabilities |
| `total_liabilities` | Total liabilities |
| `unrestricted_net_position` | Unrestricted net position |
| `total_expenses` | Total expenses used for ratio calculations |
| `charges_for_services` | Charges for services revenue |
| `general_revenues` | General revenues |
| `net_position_beginning` | Beginning net position |
| `net_position_ending` | Ending net position |
| `total_tax_supported_debt` | Tax-supported debt |
| `fmv_taxable_real_estate` | Fair market value of taxable real estate |
| `assessed_tangible_personal_property` | Assessed tangible personal property |
| `assessed_public_service_corporations` | Assessed public service corporations |
| `unassigned_fund_balance` | Unassigned fund balance |
| `assigned_fund_balance` | Assigned fund balance |
| `committed_fund_balance` | Committed fund balance |
| `other_committed_reserves` | Other committed reserves |
| `total_fund_balance` | Total fund balance |
| `total_revenues` | Total revenues |
| `debt_service_principal` | Debt service principal |
| `debt_service_interest` | Debt service interest |
| `prior_unassigned_fund_balance` | Prior year unassigned fund balance |
| `intergovernmental_operating_revenues` | Intergovernmental operating revenues |
| `enterprise_change_in_net_position` | Enterprise fund change in net position |
| `enterprise_net_transfers` | Enterprise fund net transfers |
| `enterprise_total_expenses` | Enterprise fund expenses |
